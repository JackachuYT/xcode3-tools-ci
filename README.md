# xcode3-tools-ci

Xcode 3.2.6 command line tools, gcc 4.2 and `map_fd`, packaged for the
osx360-drivers CI build.

Extracted from Apple's `xcode_3.2.6_and_ios_sdk_4.3.dmg`. Private repository,
own use only — these are Apple's packages and are not redistributed.

The CI workflow fetches them from the `xcode3-packages` release.
